Day 9 

  Given a basic HTML structure, write CSS to:

  1. Create a div with a class .box.

  2. Inside the .box, place some text content.

  3. Style the .box to clearly show:

  4. margin: space outside the box.

  5. border: a visible outline.

  6. padding: space inside the border, around the content.

  7. content: the actual text         


<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>CSS Box Model Task</title>

    <style>
        .box {
            width: 300px;
            background-color: lightblue;
            padding: 20px;
            border: 5px solid black;
            margin: 50px;
            font-size: 18px;
            text-align: center;
        }
    </style>
</head>

<body>

    <div class="box">
        cricket is a gentleman game
    </div>

</body>
</html>
