
1)Learn what attributes are in HTML. Explore how they provide extra information about elements (e.g., href, src, alt) ?

HTML attributes provide extra information about HTML elements.
They are written inside the opening tag of an element.
Attributes usually come in name="value" format.
Examples include href, src, alt, class, and id.
They help control the behavior or appearance of elements.

2. Learn how to use class for styling multiple elements with CSS. Practice applying same class to multiple tags ?

The class attribute is used to group multiple HTML elements.
It helps apply the same CSS style to many elements.
One class can be used by multiple elements on a webpage.
It is mainly used for styling and design purposes.

Example:

<p class="text">Welcome to my website</p>
<p class="text">Learning HTML is easy</p>

CSS:

.text{
color:blue;
font-size:20px;
}

3. Understand the uniqueness of id. Use it for styling and JavaScript targeting. Practice assigning unique IDs ?

The id attribute uniquely identifies an HTML element.
Each id value should be used only once in a page.
It is useful for CSS styling and JavaScript targeting.
IDs are also used for navigation within a webpage.
Example: <h1 id="title">My Website</h1>.


4.Explore the title attribute (tooltip on hover) and practice with attributes like lang, style, and hidden ?

The title attribute shows a tooltip when the mouse hovers over an element.
The lang attribute specifies the language of the webpage.
The style attribute is used to apply inline CSS styling.
The hidden attribute hides an element from the webpage.
These attributes improve usability and presentation.

5.Create hyperlinks with href. Practice absolute links (to external websites) and relative links (to local files) ?

The href attribute is used in the <a> tag to create hyperlinks.
It specifies the destination URL of the link.
Links can be absolute links (external websites).
They can also be relative links (local files).
Example: <a href="https://google.com">Google</a>.

Absolute Link

Links to external websites

<a href="https://www.google.com">Google</a>
Relative Link 

Links to local files

<a href="about.html">About Page</a>

6. Add attributes like target="_blank", download, mailto:. Create navigation between pages ?

The target="_blank" attribute opens the link in a new browser tab.
The download attribute allows users to  download a file when clicking the link.
The mailto: link opens the default email application.
These attributes enhance the functionality of hyperlinks.
They are used with the <a> tag.

Open in new tab
<a href="https://youtube.com" target="_blank">YouTube</a>
Download File
<a href="notes.pdf" download>Download Notes</a>
Email Link
<a href="mailto:example@gmail.com">Send Email</a>


7. Learn src and alt attributes. Insert images into a webpage ?

The src attribute specifies the path of the image file.
The alt attribute provides alternative text for the image.
Alt text appears if the image fails to load.
It also improves SEO and accessibility for screen readers.
These attributes are used in the <img> tag.
example
<img src="cricket.jpg" alt="Cricket stadium">

8. Practice adding image dimensions (width, height), responsive images, and clickable images (image inside <a>) ?

Image size can be controlled using width and height attributes.
This helps adjust the display size of images on a webpage.
Images can also be made clickable by placing them inside an <a> tag.
This allows the image to work as a link.
Example: Image Size
<img src="nature.jpg" alt="Nature" width="300" height="200">
Clickable Image
<a href="https://google.com">
<img src="logo.png" alt="Google logo">
</a>

9. Create a webpage with navigation links, multiple sections using IDs, and images with proper alt text and titles ?

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>My Website</title>
</head>
<body>

<h1 id="top">Welcome to My Website</h1>

<a href="#home">Home</a>
<a href="#about">About</a>
<a href="#contact">Contact</a>

<h2 id="home">Home</h2>
<p title="Home section">This is my homepage.</p>

<img src="home.jpg" alt="Home image" width="300">

<h2 id="about">About</h2>
<p class="info">I am learning HTML.</p>

<img src="study.jpg" alt="Student studying" width="300">

<h2 id="contact">Contact</h2>

</body>
</html>
